# Hindustan Tube Pro Website

Responsive static website UI inspired by the Hindustan Tube Pro Android project.

## Run
Open `index.html` in a browser, or serve the folder with any static server.

## Features
- Responsive Home feed
- Category filtering and search
- Shorts grid
- Video player modal
- Subscriptions and Library screens
- Light/dark mode
- Mobile bottom navigation
- Uses the existing Hindustan Tube Pro app logo from the Android project

## Deploy
This is a static site and can be deployed to GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any static hosting service.
